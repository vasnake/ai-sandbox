# ai-sandbox/codex

Цель проекта, расположенного здесь: дать пользователю (мне) возможность интерактивного использования AI инструментов (OpenAI Codex CLI, далее: агенты),
в процессе разработки проектов (software, data engineering), находящихся под управлением git.

Базовые требования: агенты должны быть ограничены в возможностях испортить уже работающие компоненты, системы и проекты.
Поэтому общая схема такая: агенты работают внутри докер контейнера и имеют доступ к публичным сетям,
файловым директориям с проектами. Разнообразные креды и доступы к продакшн компонентам отсутствуют в контейнере.
Агенты могут только общаться с пользователем, редактировать код в доступных проектах в файловой системе, и получать информацию из публичных сетей.
Пользователь заходит в консоль контейнера и работает с cli инструментами.

Ожидаемый пайплайн работы:
1) пользователь задает вопрос и/или задачу,
2) агент предлагает решение,
3) пользователь проверяет и уточняет;
второй и третий пункты могут повторятся много раз, в ходе интерактивной и итеративной разработки с участием агентов.
4) Пользователь принимает или отвергает решение.
